# Video Creator Skill

This skill allows the agent to create video content using `ffmpeg` and related tools in the sandbox environment.

## Capabilities
- **Sequence to Video**: Convert a series of images into a high-quality video file.
- **Overlays**: Add text, watermarks, or image overlays on top of existing video streams.
- **Editing**: Trim, concatenate, or crop video files.
- **Audio Integration**: Merge audio tracks with video or replace existing audio.
- **Format Conversion**: Convert between common video formats (MP4, MKV, AVI, etc.) and optimize for web.

## Usage
Activate this skill when you need to generate visual reports, screen recordings (simulated), or any media content processing. Use `code--exec` to run `ffmpeg` commands directly in the sandbox.
