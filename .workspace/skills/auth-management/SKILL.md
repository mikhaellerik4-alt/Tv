# Auth Management Skill

This skill allows the agent to implement secure login systems, protected routes, and session management.

## Capabilities
- **Login Systems**: Create username/password or token-based authentication.
- **Route Protection**: Implement middleware or component-level checks for authorized access.
- **Session Management**: Handle tokens and user state in local storage or cookies.

## Usage
Use this for projects requiring admin panels, user profiles, or restricted content.
