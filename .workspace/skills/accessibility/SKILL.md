# Accessibility Skill

This skill enables the agent to audit, implement, and maintain high standards of web accessibility.

## Capabilities
- Auditing components for ARIA compliance and semantic HTML.
- Implementing keyboard navigation and focus management.
- Ensuring color contrast ratios meet WCAG standards.
- Adding screen reader support (alt text, aria-labels, live regions).

## Usage
Activate this skill when a user requests an "accessibility audit", "A11y improvements", or wants to ensure their app is inclusive for all users.
