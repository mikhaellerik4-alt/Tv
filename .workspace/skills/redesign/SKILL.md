# Redesign Skill

This skill enables the agent to systematically analyze, plan, and execute redesigns of the application's user interface and experience.

## Capabilities
- Visual audit of current components and pages.
- Proposing modern design directions using `ask_questions` with prototypes.
- Iterative refinement of UI elements (typography, color schemes, layout).
- Refactoring components for better responsiveness and accessibility.

## Usage
Activate this skill when a user requests a "redesign", "UI refresh", or "visual update" for specific parts or the entirety of the project.
